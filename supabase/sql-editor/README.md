# SQL Editor import

The full seed is too large for a single SQL Editor query. Use these 24 smaller files instead (each below 48 KiB).

Your schema is already installed. Do not rerun the migration.

1. Open Supabase → SQL Editor → New query.
2. Copy the entire contents of **01-seed.sql** into the editor and click Run.
3. After it succeeds, replace the query with the next numbered file and run it. Continue through **24-seed.sql**, in the order below.
4. Run **verify.sql** after all files succeed. Expect 702 published destinations and 367 cover photos in this catalogue.

Each file is a separate transaction. If a file fails, rerun that same file before continuing. You can also safely restart from 01; catalogue inserts are idempotent. Existing visits, notes, saved places and online passport backups are not modified.
